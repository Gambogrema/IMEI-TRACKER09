IMEI-TRACKER

Présentation

IMEI-TRACKER est un projet visant à développer un outil de vérification et de gestion des numéros IMEI des téléphones mobiles.

Objectifs

- Vérifier le format des numéros IMEI.
- Contrôler leur clé de validation.
- Préparer une intégration future avec des sources autorisées permettant de vérifier les appareils déclarés perdus ou volés.

Fonctionnalités prévues

- Saisie d'un numéro IMEI.
- Validation du numéro.
- Affichage du résultat.
- Connexion future à une source de données autorisée, si un accès est disponible.

Technologies envisagées

- Python
- GitHub

Limites

Un IMEI valide ne prouve pas qu'un téléphone est légitime. La vérification du statut d'un appareil dépend de la disponibilité et de la fiabilité des sources consultées.

Statut

Projet en cours de développement.
